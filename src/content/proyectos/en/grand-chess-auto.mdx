Online multiplayer chess with a Retrowave/GTA look. It came out of hitting the walls
of an earlier version: where the original project stopped, this one starts, rewriting
the core from scratch.

## From "Phase 3" to "Reimagined"

| | Legacy (Phase 3) | Reimagined |
|---|---|---|
| Sync | `fetch` polling, slow | WebSockets via Socket.IO |
| Chess engine | Basic, incomplete | Modified Chess.js |
| Interface | Plain CSS | Glassmorphism |
| Offline mode | Didn't work | Persistent in LocalStorage |
| Security | Basic | Hardened sessions and WAF |

## Real-time sync

Every move, capture and message travels over **WebSockets**. The difference from the
old polling isn't speed: it's that the server tells you when something happens,
instead of the client asking every few seconds whether anything happened.

The clocks carry **client-server latency compensation**, which is what stops the
player on the worse connection from losing on time undeservedly.

## Infrastructure

- **Identity**: email authentication through the Resend API, signed from the
  `forcex.dev` domain.
- **Security**: Cloudflare WAF with custom rules and **Turnstile** against bots.
- **Hosting**: runs on my own server (homelab), exposed through **Cloudflare Zero
  Trust Tunnels**.

<Callout tipo="seguridad" titulo="Why a tunnel instead of open ports">
  The tunnel builds the connection from the inside out, so the router needs no port
  open to the internet. There's no surface to scan: what isn't published doesn't get
  attacked.
</Callout>
