Infraestructura & DevOps

Identidad: Autenticación mediante Resend API con correos firmados desde el dominio forcex.dev.

Seguridad: Cloudflare WAF con reglas personalizadas y Turnstile para protección avanzada contra bots.

El proyecto se encuentra self-hosted en un servidor privado (Homelab), expuesto de forma segura mediante Cloudflare Zero Trust Tunnels, eliminando la necesidad de abrir puertos públicamente.
