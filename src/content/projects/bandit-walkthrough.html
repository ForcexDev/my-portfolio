Bandit Walkthrough

Guía paso a paso para los niveles iniciales de OverTheWire Bandit.

Feb 7, 2026 ForcexDev 10 min read
Linux Wargames SSH Security

Bandit es un wargame de seguridad básico diseñado para enseñarte los fundamentos de la línea de comandos de Linux. En esta guía, cubriremos desde el acceso inicial hasta los primeros desafíos.

Meta: El objetivo principal es encontrar la contraseña para el siguiente nivel, generalmente guardada en un archivo dentro del sistema.

Level 0 -> Level 1

El objetivo es iniciar sesión en el juego mediante SSH. Los datos de acceso son:

  • Host: bandit.labs.overthewire.org
  • Port: 2220
  • User: bandit0
  • Pass: bandit0
bash 
ssh bandit0@bandit.labs.overthewire.org -p 2220

Una vez dentro, necesitamos encontrar la contraseña para el nivel 1, la cual se encuentra en un archivo llamado readme en el directorio home.

bash 
ls
cat readme

Ejecución del comando cat para revelar la primera contraseña.

Level 1 -> Level 2

La contraseña para el siguiente nivel está guardada en un archivo llamado - localizado en el directorio home.

Advertencia: Los comandos normales como cat - no funcionarán porque el sistema interpretará el guión como una opción del comando.

Para leer este archivo, debemos especificar su ruta relativa de forma explícita:

bash 
cat ./-

Conceptos Clave

A través de estos niveles, has aprendido:

  • Conexión remota mediante SSH
  • Navegación básica del sistema de archivos Linux
  • Manejo de archivos con nombres especiales
  • Uso de rutas relativas y absolutas
